# Limbo Mixology — Brand Fonts

## Eyesome (Purchased)
Used for: Titles, headers, the main app logo
Files in this folder:
- `Eyesome.otf` — Regular upright
- `Eyesome-Italic.otf` — Italic
- `Eyesome-Script.otf` — Script style

## Radley (Google Fonts — no file needed)
Used for: Body copy, labels, paragraphs, general UI text
Source: https://fonts.google.com/specimen/Radley
Loaded automatically in the app via Google Fonts CDN.
No local file required — internet connection needed to load.
